# Мой календарь

Сайт: `index.html`, `style.css`, `app.js`, `config.js`. Данные и вход хранятся в Supabase.

## 1. Настроить Supabase (один раз)

1. Supabase → **SQL Editor** → **New query**. Вставь всё содержимое `schema.sql` и нажми **Run**. Должно появиться «Success».
2. **Authentication → Sign In / Providers → Email**: выключи **Confirm email** и нажми **Save**. Тогда друзья смогут зарегистрироваться без письма.
3. В `config.js` указаны адрес проекта и publishable-ключ. Секретный ключ (`sb_secret_...`) туда класть нельзя.
4. Для кнопки «Забыли пароль?»:
   - **Authentication → URL Configuration**: Site URL и Redirect URLs = `https://colderrrrrr.github.io/calendar/`.
   - **Authentication → Emails → SMTP Settings**: свой SMTP через Gmail (`smtp.gmail.com`, порт 465, пароль приложения Google). Встроенная почта Supabase шлёт письма только участникам проекта.
   - **Authentication → Rate Limits**: 30 писем в час.

## 2. Выложить на GitHub Pages (бесплатно)

1. github.com → **New repository** → имя `calendar`, **Public** → **Create repository**.
2. **uploading an existing file** → перетащи всё из папки, кроме `README.md` и `schema.sql`: `index.html`, `style.css`, `app.js`, `config.js`, `manifest.webmanifest`, `sw.js` и папку `icons` → **Commit changes**.
3. **Settings → Pages** → **Deploy from a branch**, ветка `main`, папка `/ (root)` → **Save**.
4. Через 1–2 минуты сайт откроется по адресу `https://<твой-логин>.github.io/calendar/`.

Чтобы обновить сайт, загрузи изменённые файлы в репозиторий так же, как в шаге 2.

## 3. Поставить как приложение на телефон

- **iPhone:** открой сайт в **Safari** → кнопка **Поделиться** (квадрат со стрелкой) → **На экран «Домой»** → **Добавить**. В других браузерах на iPhone этого пункта может не быть.
- **Android:** открой сайт в **Chrome** → меню ⋮ → **Установить приложение** (или «Добавить на главный экран»).

На экране появится иконка «Календарь». Он открывается на весь экран, без адресной строки. Обновления сайта приходят сами, переустанавливать ничего не нужно.

## Как пользоваться

- Каждый регистрируется со своей почтой и паролем и видит только свои задачи.
- С телефона и с компьютера под одним аккаунтом видно одно и то же.
- Если раньше пользовался сайтом без входа, после первого входа сайт предложит перенести старые записи в аккаунт.
- Окно «Как прошёл день?» и вопросы по задачам со временем считают время по Костанаю (UTC+5).

## Если что-то не так

- «В Supabase ещё нет таблиц» — не выполнен `schema.sql` (шаг 1.1).
- «Аккаунт создан. Подтверди почту» — не выключено **Confirm email** (шаг 1.2).
- Бесплатный проект Supabase засыпает, если им не пользоваться неделю. Тогда зайди на supabase.com и нажми **Restore project**.
